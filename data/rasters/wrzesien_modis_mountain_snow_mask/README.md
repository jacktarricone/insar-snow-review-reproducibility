# External Figure 8 raster

The file `MODIS_mtnsnow_classes.tif` is not redistributed in this archive. Download and extract it from:

```text
Wrzesien et al. (2019), Global Seasonal Mountain Snow Mask from MODIS MOD10A2
DOI: 10.5281/zenodo.2626737
```

Place it in this directory or directly under `data/rasters/`, then run `scripts/03_plot_nisar_orbits_wus_map_optional.R`.
